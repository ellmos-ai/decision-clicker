# Third-party inventory

Decision Clicker has no third-party runtime dependencies. It uses the Python
standard library.

Development and release checks use `pytest`, `ruff`, `build`, setuptools, and
GitHub Actions. They are development infrastructure and are not bundled into
the runtime wheel. Their license metadata is available from their respective
distributions and repositories.

Repository history records the project maintainer as the author of the
original banner commit. The editable SVG consists of local vector shapes and
text and embeds no external font, image, icon, or model. The current PNG was
rendered directly from that SVG. No third-party dataset or copied decision
record is distributed.
